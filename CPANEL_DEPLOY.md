|---|---|

| `DB_USER` | `hause_med` |
| `DB_PASS` | *(your database password)* |
| `JWT_SECRET` | *(generate: `openssl rand -hex 32`)* |
| `ADMIN_PASS` | *(your admin password)* |

---

## Step 1 — Run the workflow

1. Go to **Actions → Build & Deploy Medsuite-eT → Run workflow**
2. Leave inputs blank and click **Run workflow**
3. Wait ~3 minutes for all jobs to complete

When done, two artifacts appear on the workflow run page:
- **`medsuite-deploy`** — the full ZIP to upload to `public_html/`
- **`medsuite-cpanel-schema`** — the seeded SQL to import into phpMyAdmin

---

## Step 2 — Import the database

1. Log in to cPanel → **phpMyAdmin**
2. Select the `hause_med` database (create it first if it doesn't exist)
3. Click **Import** → choose `cpanel-schema-seeded.sql` from the artifact
4. Click **Go**

This creates all tables and seeds both admin accounts.

---

## Step 3 — Upload and extract the ZIP

1. cPanel → **File Manager** → navigate to `public_html/`
2. If any old files exist, delete them first
3. Click **Upload** → select `medsuite-deploy.zip`
4. Once uploaded, right-click the ZIP → **Extract** → extract to `public_html/`
5. Delete the ZIP after extracting

The extracted structure should be:
```
public_html/
├── index.html          ← React SPA entry point
├── .htaccess           ← SPA routing + API passthrough
├── assets/             ← JS/CSS bundles
├── api/
│   ├── index.php       ← MySQL REST API
│   ├── config.php      ← DB credentials (generated by CI)
│   └── inc/            ← helpers, webauthn
├── icons/              ← PWA icons
├── manifest.json       ← PWA manifest
└── cpanel-schema-seeded.sql  ← (can delete after import)
```

## Troubleshooting

**Blank page / 404 on page refresh**
→ `.htaccess` is missing or `mod_rewrite` is disabled. Check File Manager that `.htaccess` exists in `public_html/`. Enable `mod_rewrite` in cPanel → Apache Handlers if needed.

**API returns "not configured"**
→ `api/config.php` was not generated. Re-run the workflow and ensure all 6 secrets are set.

**Database connection failed**
→ Double-check `DB_NAME`, `DB_USER`, `DB_PASS` secrets. On cPanel, the database and user must both exist and the user must be assigned to the database in cPanel → MySQL Databases.

**Login fails**
→ Run the schema import again — the users table may be empty. The seeded SQL is idempotent; running it twice is safe.

**HTTPS / SSL**
→ Enable **AutoSSL** in cPanel → SSL/TLS for `med-suit.shop`. The `.htaccess` does not force HTTPS; add this to the top of `.htaccess` if needed:
```apache
RewriteCond %{HTTPS} off
RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [R=301,L]
```
